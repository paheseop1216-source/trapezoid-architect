# 사다리꼴 건축가

초등학교 4학년 2학기 4단원 '사각형' — 사다리꼴 수업용 웹앱입니다.
핵심 질문: **"모든 건물은 직사각형이어야 할까?"**

- 단계: 도입 · 활동1(분류, 평행한 변 찾기, 확인 문제) · 활동2(변신 실험, 건물 디자인) · 정리
- `index.html` 한 파일로 동작해요 (빌드 도구·외부 라이브러리 없음, 오프라인 사용 가능).
- 진행 상황은 브라우저 `localStorage`에만 저장돼요. 학생 이름·개인정보는 받지 않아요.

## 실행
- `index.html`을 더블클릭하면 바로 열려요.
- 선생님 메모·발표 모드: 주소 뒤에 `?teacher=1`을 붙이거나 화면 오른쪽 아래 구석을 길게 눌러요.
- 도형 판정 자체 테스트: 주소 뒤에 `?test=1`을 붙이고 개발자 도구 콘솔을 확인해요.

## 배포 (Vercel)
정적 사이트라 별도 설정이 필요 없어요. GitHub 저장소를 Vercel에서 Import하고
Framework Preset은 **Other**, Build Command·Output Directory는 비워 두면 돼요.
